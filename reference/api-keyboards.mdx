Bots Limited provides native Python classes to make building keyboards extremely easy, eliminating the need to write raw JSON strings.

These classes are available globally in every command:
- `InlineKeyboardMarkup`, `InlineKeyboardButton`
- `ReplyKeyboardMarkup`, `KeyboardButton`, `ReplyKeyboardRemove`

---

## Inline Keyboards

Inline keyboards appear below the message they belong to. When clicked, they can send a callback query to your bot, open a URL, or open a Web App.

```python TPY Example
# Create a list of rows, where each row is a list of buttons
keys = [
    [
        InlineKeyboardButton(text="Google", url="https://google.com"),
        InlineKeyboardButton(text="Click Me", callback_data="my_button_data")
    ],
    [
        InlineKeyboardButton(text="Open Web App", web_app="https://example.com")
    ]
]

# Wrap the keys in the Markup class
markup = InlineKeyboardMarkup(keys)

# Send the message
Bot.sendMessage(chat_id=u, text="Please choose an option:", reply_markup=markup)
```

### answerCallbackQuery

When a user clicks an `InlineKeyboardButton` with `callback_data`, Telegram shows a loading spinner on the button. You **must** answer the callback query to stop the spinner. This is typically done inside the `/handler_callback_query` command.

```python TPY Example (Inside /handler_callback_query)
Bot.answerCallbackQuery(
    callback_query_id=call.id,
    text="You clicked the button!",
    show_alert=True # If True, shows an alert dialog instead of a small toast
)
```

## Reply Keyboards

Reply keyboards replace the user's default text keyboard with custom buttons. These buttons just send text back to the chat as if the user typed it.

```python TPY Example
keys = [
    [
        KeyboardButton(text="Contact Support"),
        KeyboardButton(text="My Account")
    ],
    [
        KeyboardButton(text="Send Phone Number", request_contact=True)
    ]
]

markup = ReplyKeyboardMarkup(
    keyboard=keys,
    resize_keyboard=True, # Makes the keyboard smaller
    one_time_keyboard=True # Hides the keyboard after use
)

Bot.sendMessage(chat_id=u, text="Main Menu:", reply_markup=markup)
```

### Removing the Reply Keyboard

To permanently remove a custom reply keyboard and restore the default text keyboard, use `ReplyKeyboardRemove`.

```python TPY Example
Bot.sendMessage(
    chat_id=u,
    text="Keyboard removed.",
    reply_markup=ReplyKeyboardRemove(remove_keyboard=True)
)
```

## Force Reply

Use this object to force a reply from the user. Telegram clients will automatically show the reply interface to the user.

```python TPY Example
Bot.sendMessage(
    chat_id=u,
    text="Please reply to this message with your name:",
    reply_markup={"force_reply": True}
)
```
