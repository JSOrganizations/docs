This section covers advanced interaction methods and configuration options.

## Inline Mode

Inline mode allows users to interact with your bot from any chat by typing `@your_bot_username` followed by a query.

### answerInlineQuery
Use this method to send answers to an inline query. No more than **50** results per query are allowed.

```python BLP Example
results = [
    {
        "type": "article",
        "id": "1",
        "title": "Welcome to Bots.LT",
        "input_message_content": {
            "message_text": "Bots.LT is the best platform for Bot creation!"
        }
    }
]

Bot.answerInlineQuery(
    inline_query_id=raw_message.get("id"),
    results=jsondumps(results),
    cache_time=300
)
```

## Bot Configuration

### setMyCommands
Use this method to change the list of the bot's commands. These commands appear in the Telegram menu button.

```python BLP Example
commands = [
    {"command": "start", "description": "Start the bot"},
    {"command": "help", "description": "Get help"},
    {"command": "settings", "description": "Configure settings"}
]

Bot.setMyCommands(commands=jsondumps(commands))
```

### deleteMyCommands
Use this method to delete the list of the bot's commands for the given scope and user language.

```python BLP Example
Bot.deleteMyCommands()
```

### getMyCommands
Use this method to get the current list of the bot's commands.

```python BLP Example
result = Bot.getMyCommands()
Bot.sendMessage(u, f"Current commands: {result.result}")
```

### setChatMenuButton
Use this method to change the bot's menu button in a private chat, or the default menu button.

```python BLP Example
menu_button = {
    "type": "web_app",
    "text": "Open App",
    "web_app": {"url": "https://bots.lt"}
}

Bot.setChatMenuButton(
    chat_id=u,
    menu_button=jsondumps(menu_button)
)
```
### Bot.Transfer
Use this method to programmatically transfer the ownership of the bot to another user via their registered email or username on the Bots.LT platform.

```python BLP Example
# Transfer using username
Bot.Transfer(username="new_owner_username")

# Or transfer using email
Bot.Transfer(email="owner@example.com")
```
## Internal BLP Engine Methods

### Next Command Handling
You can explicitly tell the BLP engine which command to execute on the user's *next* message using `Bot.handleNextCommand()`.

```python BLP Example
# Command 1 (/ask_name)
Bot.sendMessage(u, "What is your name?")
Bot.handleNextCommand("/save_name", {"temp": "data"})

# Command 2 (/save_name)
name = message.text
Bot.sendMessage(u, f"Saved! Hello {name}.")
```

### Triggering Other Commands
You can programmatically trigger another command's code from within your current command using `Bot.runCommand()`.

```python BLP Example
# Triggers the code inside the /help command
Bot.runCommand("/help")
```
