The Telegram Bot API is constantly updating with new features like Telegram Stars, Business features, and new message types. 

You might wonder: **"What if Telegram releases a new method tomorrow? Do I have to wait for Bots Limited to support it?"**

The answer is **No!**

## The Dynamic Fallback (`__getattr__` Magic)

The `Bot` wrapper in Bots Limited is designed dynamically. If you try to call a method on the `Bot` object that hasn't been explicitly hardcoded into our platform, the platform will automatically intercept the method name and pass it directly to the official Telegram Bot API along with your arguments.

This means **every single method listed on [core.telegram.org/bots/api](https://core.telegram.org/bots/api) is fully supported natively on Bots Limited right now.**

### How to use it

Simply take the exact method name from the official Telegram documentation and call it as `Bot.methodName()`. Pass the required parameters as Keyword Arguments (`kwargs`).

### Example 1: `setChatMenuButton`
Suppose you want to change the menu button next to the chat input field, but it's not documented in our basic API list.

```python BLP Example
# Looking at Telegram Docs:
# setChatMenuButton takes chat_id and menu_button

menu_btn = {
    "type": "web_app",
    "text": "Open App",
    "web_app": {"url": "https://example.com"}
}

# Just call it directly!
Bot.setChatMenuButton(
    chat_id=u,
    menu_button=menu_btn
)
```

### Example 2: `sendInvoice` (Payments / Telegram Stars)
Sending an invoice for Telegram Stars is fully supported.

```python BLP Example
prices = [
    {"label": "Premium Access", "amount": 500} # 500 Stars
]

Bot.sendInvoice(
    chat_id=u,
    title="Premium Access",
    description="Unlock premium features forever.",
    payload="premium_unlock",
    provider_token="", # Must be empty for Stars
    currency="XTR", # XTR is the currency code for Stars
    prices=prices
)
```

### Example 3: `pinChatMessage`

```python BLP Example
Bot.pinChatMessage(
    chat_id=u,
    message_id=message.message_id,
    disable_notification=False
)
```

## Important Rule for Dynamic Methods

Because these methods are passed directly to Telegram, the platform doesn't automatically insert the `chat_id` for you like it does for `Bot.sendMessage(u, "Hi")`. 

You **must always** use explicit keyword arguments (like `chat_id=u`, `text="..."`) when calling dynamic methods to ensure Telegram understands what you are sending.
