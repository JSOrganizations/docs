title: 'Rich Messages'
description: 'Send advanced structured messages with HTML/Markdown formatting, slideshows, tables, buttons, media, and streaming drafts.'
---

Rich messages support advanced structured formatting like headings, lists, tables, media collages, block quotations, collapsible blocks, footnotes, and LaTeX formulas.

> **Limits:**
> - Up to **32,768 UTF-8 characters** in the message text
> - Up to **500 blocks** (including nested blocks, list items, table rows, etc.)
> - Up to **16 levels** of nesting
> - Up to **50 media attachments** in total
> - Up to **20 columns** in a table

---

## sendRichMessage

Sends a rich formatted message. Use exactly one of `html`, `markdown`, or `blocks` in the `rich_message` object.

> If the message contains a media block, the bot must have the right to send that media type to the chat.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `business_connection_id` | String | No | Business connection on behalf of which the message is sent. |
| `chat_id` | Integer or String | Yes | Target chat ID or @username. |
| `message_thread_id` | Integer | No | Unique identifier for the target message thread (topic). |
| `direct_messages_topic_id` | Integer | No | Topic ID for direct messages chats. |
| `ephemeral_message_parameters` | Object | No | Parameters of the ephemeral message to send. |
| `rich_message` | Object | Yes | An `InputRichMessage` object (see below). |
| `disable_notification` | Boolean | No | Sends silently. |
| `protect_content` | Boolean | No | Prevents forwarding/saving. |
| `allow_paid_broadcast` | Boolean | No | Allows up to 1000 msgs/sec ignoring limits for 0.1 Stars per message. |
| `message_effect_id` | String | No | Unique identifier of the message effect (private chats only). |
| `suggested_post_parameters` | Object | No | Parameters of the suggested post to send. |
| `reply_parameters` | Object | No | Message to reply to. |
| `reply_markup` | Object | No | Inline keyboard to attach. |

### InputRichMessage Fields

Exactly one of `html`, `markdown`, or `blocks` must be provided.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `html` | String | No* | Message content using HTML formatting. |
| `markdown` | String | No* | Message content using Markdown formatting. |
| `blocks` | Array | No* | Message content as an array of `InputRichBlock` objects. |
| `media` | Array | No | List of `InputRichMessageMedia` objects for referencing pre-uploaded media via `tg://photo?id=`, `tg://video?id=`, `tg://document?id=`, or `tg://audio?id=` links. |
| `is_rtl` | Boolean | No | If True, message is displayed right-to-left. |
| `skip_entity_detection` | Boolean | No | If True, disables auto-detection of URLs, emails, hashtags, bot commands, phone numbers, etc. |

### InputRichMessageMedia Fields

| Field | Type | Description |
|-------|------|-------------|
| `id` | String | Unique identifier (1-64 chars, only A-Z, a-z, 0-9, _ and - allowed). |
| `media` | InputMedia... | The media to send: InputMediaAnimation, InputMediaAudio, InputMediaDocument, InputMediaPhoto, InputMediaVideo, or InputMediaVoiceNote. |

```python BLP Example (HTML Table)
html_table = """<table bordered striped>
  <caption>Student Information</caption>
  <tr><th>Roll</th><th>Name</th><th>Class</th><th>Status</th></tr>

Bot.sendRichMessage(
    chat_id=u,
    rich_message={
        "html": html_table,
        "is_rtl": False,
        "skip_entity_detection": False
    }
)
```

## sendRichMessageDraft

Streams a **partial/in-progress** rich message to the user. Ideal for AI responses that appear progressively. Draft disappears after ~30 seconds. Call `sendRichMessage` to persist.

> **Note:** Direct upload of new files is not supported in drafts. Use only already-uploaded file IDs.

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `chat_id` | Integer | Yes | Target private chat ID. |
| `message_thread_id` | Integer | No | Unique identifier for the target message thread. |
| `draft_id` | Integer | Yes | Non-zero integer identifying the draft. Same `draft_id` = animated update. Different = replaced without animation. |
| `rich_message` | Object | Yes | The partial message as an `InputRichMessage` object. |
| `can_stop` | Boolean | No | If True, shows a Stop button. Bot receives `stopped_message_generation` if pressed. |
| `keep_on_stop` | Boolean | No | If True, keeps the draft visible when Stop is pressed. |

```python BLP Example (AI Streaming Response)
# Step 1: Show Thinking animation
Bot.sendRichMessageDraft(
    chat_id=u,
    draft_id=1001,
    rich_message={"html": "<tg-thinking>Thinking...</tg-thinking>"},
    can_stop=True
)

# Step 2: Stream partial content
Bot.sendRichMessageDraft(
    chat_id=u,
    draft_id=1001,
    rich_message={"html": "<h2>Analysis</h2><p>Processing your request...</p>"},
    can_stop=True
)

# Step 3: Finalize with sendRichMessage
Bot.sendRichMessage(
    chat_id=u,
    rich_message={
        "html": "<h2>Analysis Complete</h2><p>All checks passed!</p>"
    }
)
```

## Supported HTML Tags

### Text Formatting

| Tag | Effect |
|-----|--------|
| `<b>`, `<strong>` | Bold |
| `<i>`, `<em>` | Italic |
| `<u>`, `<ins>` | Underline |
| `<s>`, `<del>`, `<strike>` | Strikethrough |
| `<code>` | Inline code |
| `<mark>` | Highlighted |
| `<sub>` | Subscript |
| `<sup>` | Superscript |
| `<tg-spoiler>` | Spoiler (tap to reveal) |
| `<tg-emoji emoji-id="...">` | Custom emoji |
| `<tg-time unix="..." format="wDT">` | Formatted date/time |
| `<tg-math>` | Inline LaTeX math |

### Links and Anchors

```html
<a href="https://t.me/">Regular URL</a>
<a href="mailto:user@example.com">Email</a>
<a href="tel:+123456789">Phone</a>
<a href="tg://user?id=123456789">User mention</a>

<tg-reference name="note-1">Footnote text</tg-reference>
<a href="#note-1">[1]</a>                    <!-- Link to reference -->
```

### Structure and Layout

```html
<h1>Heading 1</h1> ... <h6>Heading 6</h6>
<p>Paragraph text</p>

```

### Lists

```html
<!-- Unordered -->
<ul>
  <li>Item one</li>
  <li>Item two</li>
</ul>

<!-- Ordered with start, type, reversed -->
<ol start="3" type="a" reversed>
  <li>Third (c)</li>
  <li>Second (b)</li>
</ol>

<!-- With explicit item number -->
<ol><li value="7" type="i">Item seven (vii)</li></ol>

<!-- Checkboxes -->

  <li><input type="checkbox" checked> Done</li>
  <li><input type="checkbox"> Pending</li>
</ul>
```

**Ordered list `type` values:** `1` (decimal), `a` (lowercase letters), `A` (uppercase letters), `i` (lowercase Roman), `I` (uppercase Roman).

**Button types:**

| `type` | Description |
|--------|-------------|

| `copy_text` | Copies specified text to clipboard |
| `disabled` | Non-interactive disabled button |

**Button styles:** `success` (green), `danger` (red), `primary` (blue), `link` (borderless; only for `callback_data`).

## Block Reference (InputRichBlock Types)

When using the `blocks` array, each block is a JSON object with a `type` field. All 24 supported block types:

| Block Type | HTML Equivalent | Key Fields |
|------------|-----------------|------------|
| `paragraph` | `<p>` | `text` |
| `heading` | `<h1>`-`<h6>` | `text`, `size` (1-6, 1 is largest) |
| `pre` | `<pre><code>` | `text`, `language` (optional) |
| `footer` | `<footer>` | `text` |
| `divider` | `<hr/>` | none |
| `mathematical_expression` | `<tg-math-block>` | `expression` (LaTeX string) |
| `anchor` | `<a name="...">` | `name` |
| `list` | `<ul>` / `<ol>` | `items` (array of InputRichBlockListItem) |
| `blockquote` | `<blockquote>` | `blocks`, `credit` (optional) |
| `expandable_blockquote` | `<blockquote expandable>` | `text`, `credit` (optional) |
| `pullquote` | `<aside>` | `text`, `credit` (optional) |
| `collage` | `<tg-collage>` | `blocks`, `caption` (optional) |
| `slideshow` | `<tg-slideshow>` | `blocks`, `caption` (optional) |
| `table` | `<table>` | `cells` (2D array), `is_bordered`, `is_striped`, `is_compact`, `caption` |
| `details` | `<details>` | `summary`, `blocks`, `is_open` (optional) |
| `map` | `<tg-map>` | `location`, `zoom` (0-24), `width`, `height` (each 0-10000), `caption` |
| `buttons` | `<tg-button-row>` | `buttons` (1-8), `align` (left/center/right) |
| `animation` | `<video>` (gif) | `animation` (InputMediaAnimation), `caption` |
| `audio` | `<audio>` | `audio` (InputMediaAudio), `caption` |
| `document` | `<tg-document>` | `document` (InputMediaDocument), `caption` |
| `photo` | `<img>` | `photo` (InputMediaPhoto), `has_spoiler`, `caption` |
| `video` | `<video>` | `video` (InputMediaVideo), `has_spoiler`, `caption` |
| `voice_note` | `<audio>` (ogg) | `voice_note` (InputMediaVoiceNote), `caption` |
| `thinking` | `<tg-thinking>` | `text` — **draft only**, cannot appear in final messages |

**InputRichBlockListItem fields:**

| Field | Type | Description |
|-------|------|-------------|
| `blocks` | Array | Content of the list item |
| `has_checkbox` | Boolean | Optional. Add a checkbox |
| `is_checked` | Boolean | Optional. Mark checkbox as checked |
| `value` | Integer | Optional. For ordered lists, explicit label number |
| `type` | String | Optional. For ordered lists: `1`, `a`, `A`, `i`, `I` |

    chat_id=u,
    rich_message={
        "blocks": [
            {"type": "heading", "text": "Sales Report", "size": 1},
            {"type": "paragraph", "text": "Here is the summary for today."},

                "type": "table",

                    [

                    ],
                    [
                        {"text": "Widget A", "align": "left"},
                        {"text": "1,200", "align": "right"}
                    ]
                ]
            },
            {"type": "divider"},
            {
                "type": "buttons",
                "align": "center",
                "buttons": [
                    {"text": "View Report", "url": "https://bots.lt", "style": "success"},
                    {"text": "Refresh", "callback_data": "refresh", "style": "primary"}

            }

## Important Notes

- **Entity auto-detection:** URLs, emails, usernames, hashtags, cashtags, bot commands, phone numbers, and bank card numbers are detected automatically. Pass `skip_entity_detection: True` to disable.
- **Telegram link alert:** Users see an alert before opening inline links.
- **Media URL reuse:** Use `tg://photo?id=...`, `tg://video?id=...`, `tg://document?id=...`, or `tg://audio?id=...` links together with the `media` field to embed pre-uploaded files.
- **Markdown inside HTML:** Markdown is **not** parsed inside block HTML tags except inside `<details>`, `<tg-collage>`, and `<tg-slideshow>`.
- **Table cells:** Support only **inline** formatting (no nested block elements).
- **Formula source:** Treated as raw LaTeX.
- **Map constraints:** Width x height must not exceed 10,000. Width-to-height ratio must be at most 20. Zoom: 0-24.
- **Button rows:** Each `<tg-button-row>` / `buttons` block supports 1-8 buttons.
- **Draft-only blocks:** `thinking` blocks can only be used in `sendRichMessageDraft`, not `sendRichMessage`.
