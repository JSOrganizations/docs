This section covers all text and non-media interactive message types available in the Telegram Bot API.

## Sending Text Messages

### sendMessage
Use this method to send text messages.

```python BLP Example
Bot.sendMessage(
    chat_id=u, 
    text="Hello World!\nThis is a **bold** and __italic__ text.",
    parse_mode="MarkdownV2",
    disable_web_page_preview=True,
    reply_to_message_id=message.message_id
)
```

### copyMessage
Use this method to copy messages of any kind. The method is analogous to the method `forwardMessage`, but the copied message doesn't have a link to the original sender.

```python BLP Example
Bot.copyMessage(
    chat_id=u,
    from_chat_id=u,
    message_id=message.message_id,
    caption="I copied your message!"
)
```

### forwardMessage
Use this method to forward messages of any kind.

```python BLP Example
Bot.forwardMessage(
    chat_id=u,
    from_chat_id=u,
    message_id=message.message_id
)
```

## Interactive Content

### sendLocation
Use this method to send point on the map.

```python BLP Example
Bot.sendLocation(
    chat_id=u,
    latitude=23.8103,
    longitude=90.4125
)
```

### editMessageLiveLocation
Use this method to edit live location messages. A location can be edited until its `live_period` expires or editing is explicitly disabled by a call to `stopMessageLiveLocation`.

```python BLP Example
Bot.editMessageLiveLocation(
    chat_id=u,
    message_id=message.message_id,
    latitude=23.8110,
    longitude=90.4130
)
```

### stopMessageLiveLocation
Use this method to stop updating a live location message before `live_period` expires.

```python BLP Example
Bot.stopMessageLiveLocation(
    chat_id=u,
    message_id=message.message_id
)
```

### sendVenue
Use this method to send information about a venue.

```python BLP Example
Bot.sendVenue(
    chat_id=u,
    latitude=23.8103,
    longitude=90.4125,
    title="Dhaka City",
    address="Dhaka, Bangladesh"
)
```

### sendContact
Use this method to send phone contacts.

```python BLP Example
Bot.sendContact(
    chat_id=u,
    phone_number="+8801700000000",
    first_name="John",
    last_name="Doe"
)
```

### sendPoll
Use this method to send a native poll.

```python BLP Example
Bot.sendPoll(
    chat_id=u,
    question="What is your favorite programming language?",
    options=["Python", "JavaScript", "C++", "Java"],
    is_anonymous=False,
    allows_multiple_answers=True
)
```

### sendDice
Use this method to send an animated emoji that will display a random value.

```python BLP Example
Bot.sendDice(
    chat_id=u,
    emoji="🎰" # can be 🎲, 🎯, 🏀, ⚽, 🎳, or 🎰
)
```

### sendChatAction
Use this method when you need to tell the user that something is happening on the bot's side. The status is set for 5 seconds or less.

```python BLP Example
Bot.sendChatAction(
    chat_id=u,
    action="typing" # e.g., typing, upload_photo, record_video, upload_document
)
```

## Editing & Deleting Messages

### editMessageText
Use this method to edit text and game messages.

```python BLP Example
Bot.editMessageText(
    chat_id=u,
    message_id=message.message_id,
    text="This text has been updated!"
)
```

### deleteMessage
Use this method to delete a message, including service messages.

```python BLP Example
Bot.deleteMessage(
    chat_id=u,
    message_id=message.message_id
)
```
